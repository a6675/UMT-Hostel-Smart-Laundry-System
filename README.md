# UMT_LaundyOnTime 🧺
## 📌 Project Overview
** UMT Laundry-On-Time is a proposed Smart Laundry Management System designed to streamline hostel laundry operations at UMT. The system aims to eliminate long queues, notify students when their wash cycle completes. streamline maintenance reporting, and provide administrative usage insights.
